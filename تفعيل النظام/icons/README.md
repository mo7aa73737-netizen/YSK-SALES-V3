# PWA Icons

هذا المجلد يحتوي على أيقونات التطبيق بأحجام مختلفة.

## الأحجام المطلوبة:

- 72x72 - للأجهزة الصغيرة
- 96x96 - للأجهزة المتوسطة  
- 128x128 - للأجهزة الكبيرة
- 144x144 - لـ Windows tiles
- 152x152 - لـ iOS
- 192x192 - للـ Android
- 384x384 - للشاشات عالية الدقة
- 512x512 - للـ splash screens

## إنشاء الأيقونات:

1. افتح `generate-icons.html` في المتصفح
2. اضغط "توليد الأيقونات"
3. احفظ الأيقونات في هذا المجلد

أو استخدم أي أداة لتوليد أيقونات PWA مثل:
- https://www.pwabuilder.com/imageGenerator
- https://realfavicongenerator.net/
