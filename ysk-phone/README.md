# 📱 YSK Products Viewer

تطبيق PWA لعرض المنتجات وماسح الباركود الذكي المتكامل مع نظام YSK SALES.

## 🎯 المميزات الرئيسية

### 📦 **عرض المنتجات**
- عرض جميع المنتجات من Firebase
- بحث متقدم (اسم، باركود، مورد)
- إحصائيات شاملة (إجمالي، متوفر، مخزون منخفض، غير متوفر)
- عرض تفاصيل كاملة لكل منتج

### 📱 **ماسح الباركود الذكي**
- فتح تلقائي عند الطلب من النظام الرئيسي
- مسح سريع ودقيق
- إرسال فوري للنتائج
- عرض معلومات المنتج الممسوح

### 🔄 **تكامل Firebase**
- مزامنة مباشرة مع قاعدة البيانات
- استقبال طلبات المسح فوراً
- إرسال نتائج المسح للنظام الرئيسي

### 📱 **تطبيق PWA كامل**
- تثبيت على الهاتف كتطبيق أصلي
- عمل بدون إنترنت
- واجهة عربية متجاوبة

## 🚀 التثبيت والإعداد

### 1️⃣ **إنشاء الأيقونات**
1. افتح `create-icons.html` في المتصفح
2. اضغط "تحميل 192x192" و "تحميل 512x512"
3. ضع الملفين في نفس مجلد التطبيق

### 2️⃣ **إعداد Firebase**
1. افتح التطبيق `index.html`
2. اضغط أيقونة الإعدادات ⚙️
3. أدخل بيانات Firebase:
   - **API Key**: من Firebase Console
   - **Auth Domain**: project-id.firebaseapp.com
   - **Project ID**: معرف المشروع
   - **Collection Prefix**: pos (افتراضي)
4. اضغط "اختبار الاتصال" للتأكد
5. اضغط "حفظ"

### 3️⃣ **تثبيت على الهاتف**

#### **Android (Chrome):**
```
1. افتح الرابط في Chrome
2. القائمة (⋮) → "إضافة إلى الشاشة الرئيسية"
3. اختر الاسم → "إضافة"
```

#### **iPhone (Safari):**
```
1. افتح الرابط في Safari
2. زر المشاركة (□↗) → "إضافة إلى الشاشة الرئيسية"
3. "إضافة"
```

## 🎮 كيفية الاستخدام

### **عرض المنتجات:**
- **الصفحة الرئيسية**: عرض جميع المنتجات مع الإحصائيات
- **البحث**: اكتب في شريط البحث للعثور على منتج معين
- **التفاصيل**: كل بطاقة منتج تعرض السعر، الكمية، المورد، تاريخ الانتهاء

### **الماسح الذكي:**
1. **في النظام الرئيسي**: اضغط أيقونة الباركود في أي مكان
2. **تلقائياً**: يفتح الماسح في التطبيق
3. **امسح الباركود**: وجه الكاميرا نحو الباركود
4. **النتيجة**: يتم إرسال النتيجة للنظام الرئيسي وعرض المنتج

## 🖥️ واجهة التطبيق

### **الشاشة الرئيسية:**
- **شريط البحث**: للبحث السريع في المنتجات
- **بطاقات الإحصائيات**: إجمالي المنتجات، المتوفر، المخزون المنخفض، غير المتوفر
- **شبكة المنتجات**: عرض جميع المنتجات في بطاقات منظمة

### **بطاقة المنتج:**
- **اسم المنتج** مع حالة المخزون
- **الباركود** بخط واضح
- **السعر** باللون الأخضر
- **الكمية** مع تحذير للمخزون المنخفض
- **المورد** إذا كان متوفراً
- **تاريخ الانت��اء** مع تحذير للمنتجات قاربة الانتهاء

### **الماسح:**
- **شاشة كاملة** لمسح الباركود
- **رسائل توضيحية** لحالة المسح
- **إغلاق تلقائي** بعد المسح الناجح

## 🔧 الإعدادات المتقدمة

### **Firebase Collections:**
التطبيق يقرأ من المجموعات التالية:
- `{prefix}_products` - المنتجات
- `scannerSessions` - طلبات ونتائج المسح

### **تخصيص البادئة:**
يمكن تغيير بادئة المجموعات من الإعدادات (افتراضي: `pos`)

### **حالات الاتصال:**
- 🟢 **متصل**: الاتصال بـ Firebase نشط
-  **غير متصل**: لا يوجد اتصال أو خطأ في الإعدادات
- 🟡 **طلب مسح**: تم استلام طلب مسح من النظام الرئيسي

## 🔍 استكشاف الأخطاء

### ** "غير متصل"**
```
الحل:
1. تحقق من بيانات Firebase في الإعدادات
2. تأكد من الاتصال بالإنترنت
3. اضغط "اختبار الاتصال"
4. تأكد من صحة Project ID
```

### **❌ "لا توجد منتجات"**
```
الحل:
1. تأكد من وجود بيانات في Firebase
2. تحقق من اسم المجموعة (prefix_products)
3. تأكد من صحة البادئة في الإعدادات
4. تحقق من أذونات Firebase
```

### **❌ "الماسح لا يفتح"**
```
الحل:
1. تأكد من حالة الاتصال "متصل"
2. امنح إذن الكاميرا للمتصفح
3. تأكد من استخدام HTTPS
4. جرب متصفح Chrome أو Safari
```

### **❌ "النتائج لا تصل للنظام الرئيسي"**
```
الحل:
1. تحقق من حالة الاتصال في كلا النظامين
2. تأكد من تطابق إعدادات Firebase
3. تحقق من مجموعة scannerSessions
4. جرب إعادة تشغيل النظام الرئيسي
```

## 📊 الإحصائيات

التطبيق يعرض:
- **إجمالي المنتجات**: العدد الكلي للمنتجات
- **المتوفر**: المنتجات التي كميتها > 0
- **مخزون منخفض**: المنتجات التي كميتها < 10 و > 0
- **غير متوفر**: المنتجات التي كميتها = 0

## 🎨 التخصيص

### **تغيير الألوان:**
عدّل متغيرات CSS في `index.html`:
```css
:root {
    --primary-color: #1f2937;
    --success-color: #10b981;
    --warning-color: #f59e0b;
    --danger-color: #ef4444;
}
```

### **تغيير حد المخزون المنخفض:**
عدّل في `app.js`:
```javascript
// من 10 إلى 5 مثلاً
if (quantity < 5) return 'bg-yellow-100 text-yellow-800';
```

## 🔒 الأمان

- **لا يحفظ بيانات حساسة** محلياً
- **التواصل المشفر** عبر Firebase
- **أذونات محدودة** - الكاميرا فقط
- **عمل محلي** - لا يرسل بيانات لخوادم خارجية
